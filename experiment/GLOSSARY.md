## 1. 通信品質・ノイズ指標

### ■ BER (Bit Error Rate, ビット誤り率)
* **意味**: 送信された全ビットのうち、ノイズによって反転（0が1、1が0に化けた）してしまったビットの割合（%）。
* **計算式**:
  $$\text{BER} = \frac{\text{反転したビット数}}{\text{全送信ビット数}} \times 100 \quad [\%]$$
* **目安**:
  * **0.01% 〜 0.05%**: 微弱なノイズ。画像の一部タイルがちらつく程度で、多数決によりほぼ100%復元可能。
  * **0.10% 〜 0.50%**: 中程度のノイズ。多くのタイルが部分破損するが、RST区間再構築などで高い復元効果を発揮。
  * **1.00% 以上**: 壊滅的ノイズ。JPEGエントロピー符号の特性上、全タイルでハフマン同期が崩壊する過酷な環境。

### ■ ppm (parts-per-million, 100万分率)
* **意味**: 100万個の中に何個あるかを表す極微小な割合の単位。
* **換算**:
  * $1\,\text{ppm} = 0.0001\% = 10^{-6}$
  * $100\,\text{ppm} = 0.01\%$
  * $1000\,\text{ppm} = 0.10\%$

### ■ SNR (Signal-to-Noise Ratio, 信号対雑音比)
* **意味**: 信号の強さと雑音（ノイズ）の強さの比率。単位は dB（デシベル）。
* **実験での使われ方**:
  * 数値が大きいほどクリアな受信音声を表します。
  * 多数決を行う際、クリアなパケットのビットには重い票、ノイズだらけのパケットには軽い票を与える**「加重多数決の重み」**として活用されます。

## 2. 画像品質・復元評価指標

### ■ PSNR (Peak Signal-to-Noise Ratio, ピーク信号対雑音比)
* **意味**: 元の正解画像と、復元された画像がどれだけ綺麗に一致しているかを客観的に表す画質評価値。単位は dB（デシベル）。
* **計算式**:
  $$\text{PSNR} = 10 \cdot \log_{10} \left( \frac{255^2}{\text{MSE}} \right) \quad [\text{dB}]$$
  ※MSE（平均二乗誤差）は全ピクセルの色ズレの平均値。
* **目安**:
  * **100.0 dB**: ビット誤りがゼロで、送信元のJPEG画像と1ピクセルも狂いなく**「完全一致」**した状態。
  * **30 dB 〜 40 dB**: 人間の目では劣化がほとんど分からない極めて高画質な状態。
  * **20 dB 〜 25 dB**: ノイズやブロックノイズが視認できるが、元の被写体はしっかり識別できる状態。
  * **15 dB 未満**: 画面の大部分が灰色や乱れで崩れている状態。

### ■ タイル完全復元率 (Tile Recovery Rate)
* **意味**: 画像全体を構成する 256個のタイル（16×16ピクセル単位）のうち、エラーなく100%完全に復元できたタイルの割合（%）。
* **計算式**:
  $$\text{タイル完全復元率} = \frac{\text{完全復元できたタイル数 (No.1 + No.2 + No.3)}}{256} \times 100 \quad [\%]$$

### ■ ビット正解率 (Bit Accuracy)
* **意味**: 受信・多数決後のビット列が、本来の正解ビット列とどれだけ一致しているかの割合（%）。
* **関係式**: $\text{Bit Accuracy} = 100\% - \text{実効BER}$

## 3. グラフの専門用語

### ■ 混信行列 (Confusion Matrix / 遷移確率行列)
* **意味**: 送信されたビット（Tx: 0 または 1）が、受信時に何（Rx: 0 または 1）として認識されたかの遷移確率を示した 2×2 の表。
* **見方**:
  * `Tx: 0 → Rx: 0`: 正常（0のまま届いた確率）
  * `Tx: 0 → Rx: 1`: 誤り（0が1に化けた確率）
  * `Tx: 1 → Rx: 0`: 誤り（1が0に化けた確率）
  * `Tx: 1 → Rx: 1`: 正常（1のまま届いた確率）
* **対称性**: 上記の誤り確率が均等であれば、歪みのないクリーンなランダムノイズ（BSC通信路）であることを示します。

### ■ CDF (Cumulative Distribution Function, 累積分布関数)
* **意味**: 各パケットのBERが「ある値以下」になる累積確率をプロットしたS字曲線。
* **用途**: 全体の中でどれくらいの割合のパケットが低ノイズで届いているか（散らばりの偏り）を一目で把握できます。

### ■ パケット別BER分布グラフ (Packet-wise BER Distribution)
* **意味**: 送信された全256個のパケット（X軸: 0〜255）それぞれについて、ビット誤り率（Y軸: %）を棒グラフで並べたもの。
* **用途**: 全体に均等にノイズがかかっているのか、特定のパケットだけが局所的に破損しているのか（バーストノイズ）を視覚的に特定できます。

## 4. JPEGの内部構造と耐ノイズ技術

### ■ RSTマーカー (Restart Marker, リスタートマーカー)
* **意味**: JPEGのデータ列の中に一定間隔で挿入される「同期復帰用マーカー」（`0xFF 0xD0` 〜 `0xFF 0xD7`）。
* **重要性**:
  * JPEGは可変長ハフマン符号を使っているため、途中で1ビットでも狂うと以降のデータの区切りが分からなくなって画像が全滅します（ハフマン同期崩壊）。
  * RSTマーカーを挟むと、**「ここで一度デコード状態を初期化してリセット」** されるため、ノイズの被害がその区間内だけで食い止められます。

### ■ MCU (Minimum Coded Unit, 最小符号化単位)
* **意味**: JPEG圧縮を適用する最小の画素ブロック（本システムでは 8×8 ピクセルのブロック）。
* 16×16 タイルの場合、4つの MCU（左上、右上、左下、右下）で構成されます。本システムでは `restart_marker_blocks=1` を指定しているため、MCU ごとに RST マーカーが挿入され、**4つの独立したセグメント区間** に分割されます。

### ■ ハフマン同期崩壊 (Huffman Desynchronization)
* **意味**: 可変長符号において、1ビットの反転によって符号語の境界（長さ）の認識がズレてしまい、以降のすべてのデータが誤った値として解釈されて画像が市松模様や灰色ブロックに崩壊する現象。

## 5. 5段階ハイブリッド復元フロー

本システムは、受信した複数の音声パケットから以下の5段階の優先順位で画像を復元します：

```
[受信パケット群]
      │
      ▼
┌──────────────┐   Yes
│ No.1 単体無傷 ├─────────► 【即時描画確定】(最高速・無傷)
└──────┬───────┘
      │ No
      ▼
┌──────────────┐   Yes
│ No.2 全体多数決├────────► 【即時描画確定】(全ビット完全復元)
└──────┬───────┘
      │ No
      ▼
┌──────────────┐   Yes
│ No.3 RST再構築├────────► 【即時描画確定】(区間合体で完全復元)
└──────┬───────┘
      │ No
      ▼
┌──────────────┐
│ No.4 安全復号 ├─────────► 【フォールバック描画】(部分復元)
└──────┬───────┘
      │ 不可
      ▼
┌──────────────┐
│ No.5 補間処理 ├─────────► 【最終安全描画】(近傍補間・黒落ち防止)
└──────────────┘
```

| ステージ | 正式名称 | 復元の仕組み |
| :--- | :--- | :--- |
| **No.1** | **受信タイル単体での無傷チェック・即時採用** | 届いた複数パケットの中に、最初から 100% エラーのない完全な JPEG パケットが1つでもあれば、他と混ぜずにそのまま即座に採用して終了。 |
| **No.2** | **全ビット加重多数決** | 複数パケットのビット列全体で SNR 加重多数決を行い、ノイズを相殺して完全な JPEG の復元を試みる。正常にデコードできれば確定。 |
| **No.3** | **RSTマーカ区間分割による再構築・多数決** | 各パケットを RST マーカー単位（4区間）に分解し、壊れていない正常な区間同士を抽出・繋ぎ直して1枚の完全な JPEG タイルを合体生成。 |
| **No.4** | **安全デコード（最高SNRフォールバック）** | 完全復元が難しい場合、エラー耐性デコーダを用いて最も状態の良いパケットから、壊れていない部分だけをパディング補完して安全に描画。 |
| **No.5** | **グレースケール・近傍補間** | ヘッダ破損等でデコードすら不可能な場合の最終防壁。周囲の画素や灰色で補間して黒落ちを防ぐ。 |

## 6. 伝搬路ノイズモードの分類

実験スタジオでは、無線通信で実際に発生する3種類の電波障害をシミュレートできます：

1. **完全ランダム (BSC: Binary Symmetric Channel)**:
   * 全ビットに対して独立・均一な確率でビット反転が発生する標準的な白色雑音モデル。
2. **4-FSK 周波数歪み (Frequency Distortion)**:
   * SSTV Turbo の変調周波数（4値FSK: 4000Hz, 6000Hz, 8000Hz, 10000Hz）において、特定トーン間の周波数シフトや干渉による偏ったビット化けを再現。
3. **パケット分散バースト (Packet Burst / Fading)**:
   * 移動通信や電波フェージングにより、一部のパケットだけが集中的に大ダメージを受け、他のパケットは無傷で届くバースト誤り環境を再現。
